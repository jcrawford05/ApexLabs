# Formula car 3D assets

Place the demo vehicle here:

- **File:** `apex_viewport_test.glb` (binary glTF)
- **Path:** `desktop/assets/vehicles/formula_car/apex_viewport_test.glb`

Prefer `.glb` over `.gltf` so meshes, materials, and (optional) textures stay in one file.

A modular Formula-style car with separately named nodes works best later
(`Chassis`, `FrontWing`, `RearWing`, `Wheel_*`, etc.). For the first load test,
any single `.glb` is fine.
