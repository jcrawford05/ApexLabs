How data is used

Processing notes

Race identity
The historical dataset’s season and round fields identify each race. The weather file is joined using those same two fields, which avoids mismatches from Grand Prix naming changes.
Weather condition
Precipitation above zero is displayed as wet conditions; zero precipitation is displayed as dry conditions. Wind speed remains in the unit reported by the weather source.
Lap-time coverage
Lap-by-lap timing begins in 1996, so pace visuals show an unavailable-data state for earlier races instead of implying a zero value.
Historical interpretation
Season ranks are calculated from points in the supplied race-result data and may differ from official standings in historical seasons that used dropped-score rules.
